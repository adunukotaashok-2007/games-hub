# games-hub
This game strips away the noise of larger group dynamics to deliver a pure, high-stakes tactical showdown. Every decision you make directly impacts your opponent. Every resource you claim is one they cannot have.
# 🎮 30 Games Hub

A multiplayer collection of mini games.

## Features

- Single player
- Play against bot
- Local 2-player
- Online multiplayer architecture
- Game hub
- Responsive web interface
